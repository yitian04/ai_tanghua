# ai_tanghua

糖画机械臂的图像生成、线稿检查、曲线转换、轨迹规划与执行项目。

## AI 模型接入

AI 糖画页面使用 `@earendil-works/pi-ai` 提供模型目录、OAuth/订阅登录、API Key 和生图调用。首次使用除 Python 依赖外，还需安装 Node.js 22.19 或更高版本，并在项目目录执行：

```powershell
npm install
```

详细使用方式和限制见 [AI 糖画样图与线稿模块](docs/ai_sugar_painting_module.md)。

### 使用硅基流动

1. 在硅基流动控制台创建 API Key 并确保账户有可用余额。
2. 启动项目，进入“AI糖画线稿 → 模型配置”。
3. 接入方式选择“硅基流动（中国大陆 API）”。
4. 保留默认配置：
   - 样图生成模型：`Qwen/Qwen-Image`
   - 线稿编辑模型：`Qwen/Qwen-Image-Edit-2509`
   - API 地址：`https://api.siliconflow.cn/v1`
   - 样图尺寸：`1328x1328`
5. 输入 API Key，点击“测试并保存连接”。密钥将保存在本机 `data/model_gateway/siliconflow.json`，新建任务或重启项目后无需重新输入。

也可以在启动应用的同一个 PowerShell 窗口中设置密钥：

```powershell
$env:SILICONFLOW_API_KEY="sk-你的密钥"
.\.venv\Scripts\python.exe start_app.py
```

项目会用文生图模型生成样图，再用编辑模型把确认的样图转换成线稿。测试连接只读取模型列表，不会发起付费生图；点击生成或重新提取时才会产生图片调用费用。

新建任务区域可以在“中文 / English”之间切换提示词语言。确认 AI 线稿并进入“图像转曲线”后，系统默认选择“仅提取线条骨架”，所有有效区域按线条处理，不执行面域轮廓提取。

样图和线稿阶段分别使用独立的正向、反向提示词：正向提示词只描述目标画面，反向提示词集中排除填充块、断线、孤立糖线以及粘连或交叉的排线。图像转曲线默认关闭模糊和断点膨胀连接，以免相邻排线被横向粘成一组；需要修补真实小断口时，可手动逐级增加“连接小断点”。

### 项目默认值与本机隐私

两个阶段都可以编辑正向、反向提示词，并选择“仅应用到当前任务”或“应用并保存为项目默认”。模型配置中的“保存为项目默认模型”只记录服务商和模型 ID。可随项目提交到 GitHub 的默认值统一保存在：

```text
config/ai_generation_defaults.json
```

该文件不包含 API Key、图片 URL 或生成结果。API Key、OAuth 凭据、上传缓存、生成图片、任务记录与曲线结果均保存在 `data/`，已由 `.gitignore` 排除；`.env` 和 `.streamlit/secrets.toml` 同样不会提交。上传前仍建议执行 `git status`，确认暂存列表中没有个人文件。

提示词界面会把包含当前主体名称的固定首行单独显示。该行不可编辑，也不会写入项目默认提示词；实际调用模型时，会自动放在可编辑提示词正文之前一同发送。反向提示词允许留空：硅基流动适配器会将非空内容作为独立参数发送，BananaPro 会将其追加到主提示词，Pi 模型网关和通用兼容适配器目前不单独发送反向提示词。所有提示词源码和项目默认配置统一使用 UTF-8。
