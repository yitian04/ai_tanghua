# 全局素材库

侧栏“素材库”打开管理弹窗，替代原历史数据清空入口。
旧的一键绘制、设计输入已从导航移除，底层文件保留。

分类为图像、曲线 JSON、轨迹、执行文件（URP）、SVG。文字轨迹和合成轨迹列入轨迹分类；
G-code、URScript 仍可在全部及轨迹中管理。扫描现有成果目录，不移动历史文件，不收录模型凭据、任务记录或临时测试产物。
首次扫描在后台按内容校验文件，已完成的素材先显示；已验证且未改变的文件复用缓存。
缩略图先显示灰色类型图标，逐个加载，不等待整页完成。新增成果无需登记，可刷新查看。

每个模块的文件输入只提供“本地上传”和“从素材库选择”。除合成对象的直接导入外，本地上传在弹窗里预览确认后，
才按类型保存到 images / curves / trajectories / compositions / exports。
同名文件自动增加后缀，不覆盖已有内容。素材库选择只引用现有文件，不重复保存。
图片与轨迹确认后不会自动生成或执行；模块原来的处理按钮仍需点击。
模块间传递的成果需通过“预览并确认上一步成果”确认；文字成果进入合成时点击“添加上一步轨迹”直接添加。

轨迹合成支持多选 JSON/CSV：从素材库勾选后，右下“导入轨迹”可用时高亮；
直接按选择顺序加入对象列表，不再预览确认或二次点击添加。点击轨迹卡片也可勾选。
本地上传支持多文件，右下按钮直接校验、归档并添加；全部文件校验通过后才添加对象。
每批新增对象可以一次撤回，重复点击事件不重复添加，同一素材仍可在下一次导入时再次添加。
已批准参考样本的上传只接受与批准样本一致的图片，普通图片请使用第二阶段参考图入口。
SVG 作为源图管理，新导入的 SVG 保存在 images；历史 SVG 保留原位，不属于曲线格式。
“图像转曲线”接受图片和 SVG：SVG 直接采样路径，不经过二值化或骨架提取。
图片的骨架模式先拓扑细化粗线（不是腐蚀），再逐边遍历全部骨架连接，避免把多分支图误判为单环或只保留最长路径。
保留交叉点间短线，共享交点坐标；近直线校正、轻度平滑和有界曲线插值保持端点固定。默认最大处理边长提高至 2048。
骨架模式不应用短曲线长度过滤或近邻重复线删除，避免删掉有意义的短连接；独立小噪点仍由最小连通区域面积过滤。
确认转换后仅保存曲线 JSON，供轨迹规划使用；图片转换、一键流程及 AI SVG 实验也仅保存 JSON 曲线成果。
SVG 采样预览支持调整间距，不会自动把实心轮廓变为中心线；裁切、蒙版、文字等尚不支持的内容须先展开为普通路径。
支持 Illustrator 的 `defs/style` 简单样式：元素、类名、ID 选择器及逗号并列规则；按优先级应用描边、填充、显示隐藏等属性，行内样式优先。编辑器 metadata 不参与采样。
外部样式、复杂选择器、样式中的滤镜或 URL 引用，以及 defs 内的裁切、蒙版、可复用图形等仍明确拒绝。
SVG / 曲线 JSON 的预览左侧提供“转为 JSON 并入库”或“转为 SVG 并入库”。转换保存为新素材，不覆盖或替换当前预览；
SVG 始终作为源图归档到 images，曲线 JSON 归档到 curves。上传确认预览也可直接转换，只保存转换结果；回收站不提供转换。
同一预览中的已转换按钮禁用，重新打开预览可再次转换；同名结果自动加后缀。JSON 转 SVG 使用当前采样点列，保留坐标和笔顺，不重建原始贝塞尔控制点。
G-code、URP 和 URScript 可以管理，但只会在兼容的模块输入中出现。
无法可靠还原图形的执行文件显示内容摘要，素材库不解释执行程序、也不连接机器人。

点击卡片进入预览，不再提供独立预览按钮。卡片右上删除按钮直接移入
data/.asset_trash，不弹确认、不级联删除其他成果。
标准轨迹详情使用[执行模拟器](trajectory_playback.md)，支持出料状态、倍速和按笔跳转；缩略图仍保持静态。
回收站可以恢复；恢复时同名文件不覆盖。单个永久删除、批量永久删除、清空回收站均需警告确认。
确认框打开后新增的回收站文件不包含在本次确认范围内；Escape 只取消警告，保留素材库。
文件被外部修改后需刷新重新选择；失效输入会清除并提示。
合成页已导入对象与源素材独立，删除原文件不删除当前布局对象；不支持合成工程文件。

基础搜索按文件名称匹配；排序支持修改时间倒序和名称，每页最多 24 项。
筛选、搜索和管理动作位于固定左栏，只有右侧素材框滚动，分页固定在右下角。
正文关闭按钮已移除，使用右上角 ×。
左栏“打开本地文件夹”打开本机 data 目录（回收站视图打开回收站目录）；
详情“在文件夹中显示”打开所在目录并选中文件，也适用于模块导入预览。
尚未确认上传的文件不落盘，因此该按钮不可用。此功能打开运行应用的这台电脑上的文件夹。
`data` 仅存放素材、任务、连接配置及素材库缓存/回收站。旧的
`software_checks`、`vectorization_temp` 和空的 `direct_curves` 已移出 data，
归档于 `.artifacts/retired_data_20261103_1514`。新的软件检查输出统一写入
`.artifacts/software_checks`；转换中间文件使用系统临时目录。
保留 `generated`、`direct_curve_demo` 中的现有素材以及 `model_gateway` 本机连接配置。
全局管理支持多选、全选本页、清空选择；右下“放入回收站”有选择时高亮，直接批量操作。跨页和跨筛选保留已选项；
管理多选时禁用预览，退出时清空管理选择。回收站也支持多选永久删除。
部分操作失败会保留失败项选择，可在右下“失败 N 项”展开原因。
回收站页面及普通按钮采用淡灰底，“返回素材库”保持白底；批量永久删除入口也位于右下，仍需警告确认。
返回素材库后，页面及普通按钮明确恢复白底，反复切换不保留回收站的灰色主题。
模块导入弹窗不提供管理删除功能；其他模块的输入预览确认流程保留。

索引与缩略图缓存保存在 data/.asset_cache，可删除后重建，不属于源素材。
目录刷新只读取基本信息，新增或变化的文件重新校验；预览确认与删除仍检查原文件内容。
后台最多两个工作线程，几何绘图串行保护；只生成当前页缩略图，翻页取消旧页待处理任务。
第一版不包含标签、收藏、来源追踪、重复内容提示或批量打包。

软件检查：`python -m unittest discover -s tests`；浏览器检查
`python tests/browser_assets_check.py http://127.0.0.1:8520`。
管理与滚动检查：`python tests/browser_asset_manager_check.py http://127.0.0.1:8520`。
两者需 Playwright 与 Chrome，测试应用需已启动，只删除自身创建的测试素材。

性能检查：`python tests/benchmark_asset_library.py` 将当前有效素材复制到临时目录，
用独立缓存测量，不删除应用缓存或修改源文件。结果保存至
`.artifacts/software_checks/asset_performance.json`。
2026-11-03 的 134 项素材快照：原完整扫描 3.75 秒；冷缓存框架可用 0.49 秒，
首个有效素材 0.51 秒，后台完整校验 4.74 秒；暖缓存列表 0.55 秒。
浏览器翻页约 0.19 秒，暖启动首批卡片约 0.28–1.05 秒，随运行负载变化；
这些首屏时间不包含后续缩略图补齐。
