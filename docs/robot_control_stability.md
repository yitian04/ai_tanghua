# UR5／CB3 受监控任务控制

本实现不修改 `ur_robot_control`。导入模块、打开机器人页、恢复参数均不会连接设备。
软件停止与心跳不属于安全认证功能，不能替代实体急停、控制器安全配置和失效关阀硬件。

## 版本与依赖

- UR 官方 RTDE Python Client v2.7.12 固定为提交 `29f02eb0d5164b03a0a95dfd4f4f8645be12aa59`，通过 requirements 安装，保留上游 BSD 许可。不是 SDU 的同名用途库。
- 首版接收 CB3 PolyScope 3.9+，仍须针对实际版本进行 URSim 和现场核验；不识别、字段缺失、输入字段被占用时禁止运动。
- 3.12.3 起读取 RTDE `tcp_offset`。较早版本手工填写示教器中的 TCP 偏移，脚本启动前使用 `get_tcp_offset()` 核对，不能跳过核对。
- Dashboard 29999：严格响应解析；30002：运动脚本和仅 I/O 的 `sec` 程序；RTDE 30004：状态、输入、倍率。

## 工作区示教（简化版）

1. 填写 IP，按需点击诊断；页面不会自动连接。用示教器定位并停稳，分别记录准备姿态、落笔姿态、左上／左下／右上／右下四角。
2. 准备姿态同时作为允许启动位置，执行结束回到这里。落笔姿态只确定绘制 Z 与工具旋转向量；TCP 偏移是法兰到工具尖端的标定，不是落笔位置。
3. 四角在水平绘制台面上记录：X 向右、Y 向下。首版要求区域与机器人基座 XY 对齐。高度差超过 1 mm、方向偏差超过 1°、边界不一致超过 2 mm 时拒绝保存，不能用包围框掩盖错误。
4. 填相对台面的抬起高度，保存工作区。保存“轨迹规划默认设置”只原子更新规划的中心、宽高、绘制 Z、工具朝向、抬笔高度的默认和最近值，不修改速度、已有轨迹或临时编辑结果。
5. 工具标定、出料端口、接线和寄存器在折叠设置中配置。有障碍时在高级设置分别读取进入和返回中间点，没有障碍不必填写。
6. 导入轨迹，点击“关料试运行”（真实运动，但不出料）。软件确认当前任务完整结束后，操作员确认整段进入、工作区上方横移、抬离及返回无障碍，点击“确认本配置已验证”。之后可以“正式绘制”，不要求每次试运行。

简化路线是：已处于准备位 → 可选进入绕障点 → 工作区中心上方 → 首点上方 → 落笔 → 原轨迹 → 关料抬离 → 工作区中心上方 → 可选返回绕障点 → 准备位。中间点不自动倒序，进出段始终低速、关料、不做圆滑过渡。

读取不驱动机器人；记录点或四角校验不构成碰撞证明。停止后不执行上述正常返回路线。修改配置撤销验证。旧记录完整保存在迁移数据中，可复用准备位和 TCP，但必须补录落笔及四角并重新试运行。

工作区示教和执行参数旁的 `ⓘ 操作说明` 提供操作步骤、单位、参数用途和常见错误说明。

## 心跳、任务和停止

- 任务在进程级服务中运行，不阻塞 Streamlit 页面。按 IP 排他，系统文件锁阻止另一服务进程同时启动；部署仍限定单个控制服务实例，不面向多机竞争。
- 输入整数寄存器 24：心跳计数；25：本次任务编号；26：停止请求；27 预留。输出 25：任务编号；26：阶段（0 等待，1 运动，4 完成，-1 异常）；27：完成编号。不使用 0–23。
- 启动脚本先关料、配置停止低电平、等待一跳新心跳，再核对当前关节位置、实际 TCP 和任务编号；这些条件满足前不运动。
- 网页每 0.5 秒报告在线；超过 3 秒，后台请求停止。隐藏页面不发送在线报告，因此切换到后台超过阈值也会终止任务。
- 后台每 0.25 秒写心跳；CB3 控制循环按 8 ms 计数，250 个未更新周期触发本地关料、终止运动线程、`stopj(1.0)` 并终止程序。调度、控制器负载和减速会影响实际停止时间，2 秒不是安全额定响应上界。
- 停止通道独立，不等发送或运动线程；依次发送 RTDE 停止/关料、I/O-only `sec` 关料和 Dashboard stop。读取反馈确认停止；失败仍可反复核对，未知状态保留运动锁。
- 停止没有自动抬笔、返回、续画或重发。正常完成才执行关料、抬离和示教返回路线。
- 整个任务目前固定 10% 控制器速度倍率，包括绘制；`movel` 指令先取轨迹速度与执行上限的较小值，再受倍率、加速度和控制器限制影响。没有隐藏的 5 mm/s 下限。
- 发送前持久标记 `motion_send_attempted=true`。从未尝试发送运动、且没有运行线程时，点击停止不会锁成“停止中”；失败显示“未连接，停止请求未确认”，可以清除提示，但不声称设备已停稳。
- 已尝试发送运动后失联仍为“结果未知”；只能核对设备反馈解除锁。旧的无任务编号空闲停止记录可恢复；不确定的历史记录不能用清提示解锁。
- 服务重启时未结束且可能已发送运动的记录变为“结果未知”；重新连接不恢复任务。

## 导出与存储

- 示教路径：`data/.robot_config/<ip>.json`；任务状态：`data/.robot_state/<ip>.json`，均不进入素材库。
- 标准轨迹 JSON/CSV 的格式和点序不变。机器人页不再把宽松解析的通用 G-code 直接作为带料执行输入。
- URP／脚本导出需要已验证路径，使用相同的进出、心跳和关料编译器。文件带有项目控制清单（轨迹、路径、导出时参数）。
- 在机器人页导入本项目导出的 URP／脚本后，校对当前路径内容，按清单重建本次任务标识并由任务服务执行；不 eval 任意脚本。未知程序拒绝执行。
- URP 文件自身不会启动 PC 心跳。**不能作为脱离任务服务的独立示教器程序使用**；无有效任务编号／新心跳时启动守卫会终止且不运动。部署到 PolyScope 的兼容性必须另外验证。
