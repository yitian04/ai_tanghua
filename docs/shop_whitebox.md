# 理想小店（白盒）

第二轮策略更新：六个按钮按线条组织重新分类，18条推荐主要覆盖植物、风景、食物和静物；统一要求极简单色等粗长线。生成目标只描述独立内容，移除正向提示中的店铺与橱窗语义；不再输入艺术家彩图拼贴。共用sample阶段默认已按九张同题比较结果改为GPT Image 2。检查返回尺寸；近似16:9只补极窄白边，原图另存，明显比例错误拒绝，不拉伸。比较原图和判断依据见 `outputs/shop_model_comparison_v2`。

侧栏的“理想小店（白盒）”入口提供绘制、描述生成、抽签三种交互。页面采用左侧说明、中间模板橱窗、右侧操作和底部步骤布局；窄屏按容器宽度折叠。旧的本地示例实验保留在 `render_example`，不作为默认界面。

手绘支持鼠标、触屏、整笔擦除、撤销和清空。一次落笔到抬笔记录为一条曲线；点列和笔画列表保留原始次序，记录800×456画布，不记录时间和速度。手绘直接复用橱窗曲线合成，保存时包含原稿和合并曲线两个JSON。修改后旧合成不可保存；打印仍使用现有轨迹优化和工艺速度。

AI支持描述、六种候选画风单选、同画风内随机灵感（不连续重复）与参考图生成。画风切换不覆盖描述，随机灵感不自动生图。优先复用AI生图模块会话中的实际服务和参数；尚未访问该模块时使用项目已保存的sample阶段模型与本机凭据，不提供配置入口。支持图片输入时以候选风格与森林样板组合作为参考；只支持文生图的当前模型仍使用该模型，不切换到另一个编辑模型。生成图为草稿，显式保存后入库。

抽签提供晴天、彩虹、枝叶、雪花、花朵、雨天、阴天七个等概率扇区。随机数采用拒绝采样，指针与结果对应；旋转时禁止重复触发，减少动态效果设置下直接呈现结果。抽签不会调用模型。

以下为保留的本地示例实验说明：

默认样例保存在 `resources/shop_whitebox`，首次进入经素材服务导入素材库，不覆盖同名文件。运行时从素材库读取；不依赖下载目录或微信临时路径。模板为曲线 JSON，图片支持透明底并按白底解释。

左侧可替换模板和示例图片。默认橱窗范围为 x=38.9–482.6、y=144.6–397.2（模板坐标）；更换模板后须展开高级设置，核对边界并勾选确认。连接容差默认为 2，重合容差为 0.5，均使用模板坐标单位。

“提取并合成”复用本机骨架提取算法，将完整素材画布铺满橱窗，切分越界线段，将容差内端点连接到实际窗框，剔除窗框重合段。不为内部孤立元素自动加线，不修改模板原坐标和闭合状态；模板曲线在前，内容曲线在后，统一重新编号。

右侧可查看模拟素材、内容曲线和完整小店，支持点击放大。仅最终合并曲线 JSON 可以入库或下载。输入发生变化后，旧结果标记过期，禁用保存和进入轨迹规划，直到重新生成。

使用现有草稿保存与离页确认机制，“进入轨迹规划”将已保存的曲线交接至规划模块。不生成机器人程序，也不执行机械臂。连通性统计只描述二维几何关系，不代表制造质量或一笔完成。
