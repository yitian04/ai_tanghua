# 文字轨迹与轨迹合成

安装：`npm install`，然后用项目 Python 执行 `pip install -r requirements.txt`。
界面需要 Streamlit 1.58 或以上。生成与排布不访问外部服务，不调用付费模型。

## 文字轨迹

中文使用 hanzi-writer-data 2.0.1 的 `medians`，字库位于
`node_modules/hanzi-writer-data`。不要把 `strokes` 封闭轮廓作为中心线。
汉字统一按 1024 字格转换，`y=(900-y_source)/1024*字高`。
英文、数字和 ASCII 标点使用 Hershey-Fonts 2.1.0 的 futural。
支持空格和显式换行，不自动换行；缺字或中文标点会阻止生成并列出字符。
字格中心定位到输入的机器人中心；字形原有留白保留。

生成曲线和轨迹保存至 `data/text_trajectories`，可下载 JSON，或加入合成。
曲线保存为 `layout_mm`，生成器使用 `preserve_mm` 规划模式保留字号与间距，
关闭笔顺优化。不要把这些毫米曲线直接交给旧的自动适配模式，否则尺寸会改变。

## 合成

导入项目标准 trajectory JSON/CSV，每个文件是独立对象，可重复导入。
支持从素材库多选或一次上传多个文件，点击右下“导入轨迹”直接加入对象列表；
无需预览确认或再点击添加。导入顺序沿用勾选/上传顺序，一批导入可一次撤回。
拖动移动，拖角点等比缩放，方向键移动 1 mm（Shift 为 10 mm）。
角点外侧出现旋转光标时可拖动旋转，按住 Shift 吸附到 15° 的整数倍。
右侧对象管理列表可拖动每行的抓手调整绘制顺序（从上到下）；行尾 × 删除该对象。
越界元素在列表中用红字和浅红底标记，移回画布后恢复；拖拽过程中同步更新。
较长的列表保留滚动位置：在底部编辑、删除或重排后仍停留底部，新增对象会跟随新项；
在中部操作则保留当前可见内容，不随页面同步跳回列表顶端。
列表排序与画布叠放相互独立，选中对象置于预览最上层，导出仍严格按列表顺序执行。
布局页支持 Ctrl+Z 撤回、Ctrl+Shift+Z / Ctrl+Y 重做、Ctrl+C 复制选中对象、Ctrl+V 粘贴、Delete 删除；
macOS 可使用 Command。文字和数值输入框保留原生编辑快捷键，不触发对象操作。
复制粘贴为本次会话内的对象剪贴板，副本使用独立编号并偏移 10 mm；不会覆盖系统文字剪贴板。
最近 50 步布局修改可撤回，包括导入、变换、改名、排序、删除和共同平面设置；
离开模块会清除当前排布和撤回记录。
属性区域可精确填写中心位置、宽或高、比例、旋转角度；尺寸调整只改宽或高一项。
旋转以对象中心为轴，正角度在画布上顺时针。列表上下顺序即最终执行顺序。

画布坐标：左上为 (0,0)，右为 +X，下为 +Y。
`robot_x=canvas_x + center_x - width/2`，Y 同理，不再自动适配缩放。
新对象按原毫米尺寸居中；对象之间允许重叠，越界则阻止导出。
绘制段按 drawing 状态及曲线边界切分，保留点序、方向、速度；统一 Z、抬笔高度与姿态。
对象间重新插入不出料的抬笔、空走和落笔点，不保留原始非绘制轨迹。

合成结果先作为草稿，仅生成一个标准轨迹 JSON；点击“保存至素材库”后入库，
可直接交给“数字文件”页。模块不支持合成工程的导入、下载或保存。
历史工程文件保持原位，但不再作为可导入素材收录。拖拽同步完成后再保存。

## 数据来源与许可

- [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)：2.0.1，字形数据采用
  Arphic Public License，**不等同于 Hanzi Writer 程序的 MIT**。
  原许可随 npm 包保存在 `node_modules/hanzi-writer-data/ARPHICPL.TXT`；
  再分发原数据时必须保留，修改数据时遵守其中的修改及再分发条款。
  本模块仅读取原始数据，不改写上游字库。
- [Hershey-Fonts](https://github.com/apshu/HersheyFonts)：2.1.0，代码及字形的许可声明随
  Python 包分发；二次打包时保留包内许可与原字形来源说明。

后续排布策略应输出同一套对象变换：先实现几何模板，后接视觉模型建议，
不能让模型直接改写有序轨迹点。当前没有视觉模型调用或机器人自动执行入口。

## 软件检查

`python -m unittest discover -s tests` 包含文字尺寸、笔顺、坐标变换、导入校验与合成连接检查。
可选浏览器检查：安装 `playwright`，启动本地 Streamlit 应用于 8512 端口，
然后执行 `python tests/browser_trajectory_smoke.py`（使用已安装的 Chrome）。
浏览器检查截图与工程下载保存在 `.artifacts/software_checks`，不属于实际制作验证。
